Original Java mod source assets retained for ongoing conversion.

The 85 entity animation JSON files, 92 entity geometry JSON files, 33 particle JSON files, 113 OGG sounds, and 22 armor geometry models were copied into Bedrock Resource Pack locations. Matching entity definitions were wired where a compatible identifier and texture were available.

The 863 Java recipe JSON files and 382 Java NBT structure files are preserved here as reference source. Java custom recipe serializers and Java NBT structures are not directly loadable by Bedrock. Converted recipe coverage and known limitations are listed in JAR_SOURCE_INVENTORY.json. These raw reference files are not active Bedrock recipes/structures.
